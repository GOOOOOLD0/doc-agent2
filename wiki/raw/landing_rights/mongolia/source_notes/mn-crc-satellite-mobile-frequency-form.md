# Source Note：移动卫星业务频率申请表

## 1. 来源信息

| 项目 | 内容 |
| --- | --- |
| 来源名称 | 表格 `ТЗ_9.8` 附件 3“移动卫星通信服务频率/频段使用站” |
| 发布机构 | 蒙古通信监管委员会（CRC） |
| 来源类型 | PDF，4 页 |
| 原始链接 | 见 YAML `source_url` |
| 本地来源路径 | `wiki/raw/landing_rights/mongolia/sources/mn-crc-satellite-mobile-frequency-form/snapshots/2026-07-26/original.pdf` |
| 来源语言 | 蒙古语，技术字段含英语 |
| 抽取日期 | 2026-07-26 |

## 2. 主要内容摘要

1. 本表用于移动卫星通信服务的频率/频段特别许可申请。
2. 表格把 GMPCS、Inmarsat、Iridium、Globalstar 和其他系统作为业务选项。
3. 申请字段包括设备位置、型号、Tx/Rx、带宽、数量、功率、服务半径、签约运营商和卫星名称。
4. 表格同样引用第 37/2022 号决议第 4.8 条的卫星信道租用能力证明及后续合同副本要求。

## 3. 主要原始信息

- 申请人基本信息、业务必要性、设备认证、系统图、覆盖图、商业计划和实施进度；
- 移动卫星系统名称和业务说明；
- 设备地理位置、经纬度和技术参数；
- 签约运营商及关联卫星；
- 设备负责人员信息。

## 5. 信息不足或需人工复核

- 表格没有解决第 37/2022 号决议第 4.5 条是否完整排除第 9.10 项许可的问题。
- “位置”字段是否适用于每台移动终端、批量终端或仅网络控制设备，需向 CRC 确认。
- 表格未标明发布日期或版本号；其现行性以 CRC 当前页面仍嵌入该 PDF 为依据。
