# [[concepts/radio_rules/article_1|第1条]] — 第06节

## 概念定义

来源于《无线电规则：2020年第1卷——条款》（2020）第15页 至 第32页。

[[concepts/radio_rules/article_1|第1条]]第6节（条款1.137-1.165）定义了无线电发射与无线电设备的核心技术特性，涵盖辐射与发射的基本概念、发射类别（含单边带发射的三种子类型）、无用发射的分类体系（带外发射/杂散发射/无用发射及其频域划分）、频率与带宽参数（指配频段/频率、特征频率、基准频率、频率容限、必要带宽、占用带宽）、极化方式（右旋/左旋）、功率表征体系（峰包功率/平均功率/载波功率及符号约定）、天线增益的三类基准（全向/半波振子/短垂直天线）、等效辐射功率的三种形式（e.i.r.p./e.r.p./e.m.r.p.）以及对流层散射和电离层散射两种传播模式，并附有带外发射/杂散发射/无用发射术语的六种工作语文对照表。

| 1.142 | 减载波单边带发射：载波受到一定程度抑制但仍可得到恢复并用于解调的单边带发射。 |
| 1.143 | 抑制载波单边带发射：载波全部被抑制并不拟用于解调的单边带发射。 |
| 1.144 | 带外发射*：由调制过程产生、刚超出必要带宽的一个或多个频率上的发射，但杂散发射除外。 |
| 1.145 | 杂散发射*：在必要带宽之外的一个或多个频率上的发射，其发射电平可以降低而不致影响相应信息的传输。杂散发射包括谐波发射、寄生发射、互调产物及变频产物，但带外发射除外。 |
| 1.146 | 无用发射*：包括杂散发射和带外发射。 |
| 1.146A | （发射的）带外域：通常以带外发射为主的紧邻必要带宽的频率范围，但不包括杂散域。以其来源为基础定义的带外发射在带外域发生，在杂散域亦有轻微程度的发生。同样，杂散发射可能在带外域发生，亦可能在杂散域发生。（[[concepts/radio_rules/wrc-03|WRC-03]]） |
| 1.146B | （发射的）杂散域：通常以杂散发射为主的带外域以外的频率范围。 （[[concepts/radio_rules/wrc-03|WRC-03]]） |

| 1.150 | 基准频率：相对于指配频率来说具有固定和指定不变位置的频率。此频率对指配频率的偏移与特征频率对发射所占频段中心频率的偏移具有相同的绝对值和符号。 |

| 1.155 | 左旋（逆时针）极化波：在任何一个垂直于传播方向的固定平面上，顺着传播方向看去，其电场向量随时间向左或逆时针方向旋转的椭圆极化波或圆极化波。 |

| 1.158 | （无线电发信机的）平均功率：在正常工作情况下，发信机在调制过程中以与所遇到的最低频率周期相比的足够长的时间内，供给天线馈线的平均功率。 |

## 关键条款 / 关键观点

- **1.138 发射 vs 1.137 辐射**：明确区分"发射"（由发射电台产生）与"辐射"（任何来源的无线电波能量流），例如接收机本振辐射属于辐射而非发射。
- **1.139 发射类别**：用标准符号标示发射的一组特性，包括主载波调制方式、调制信号、发送信息类型等，是后续[[concepts/radio_rules/appendix_1|附录1]]发射标识体系的基础。
- **1.140-1.143 单边带发射三类细分**：全载波（载波不抑制）、减载波（载波部分抑制但可恢复用于解调）、抑制载波（载波全部抑制且不用于解调），体现频谱效率的递进关系。
- **1.144-1.146B 无用发射三层分类体系**：带外发射（调制产生，刚超出必要带宽）、杂散发射（谐波/寄生/互调/变频产物，可降低而不影响传输）、无用发射（两者之和），[[concepts/radio_rules/wrc-03|WRC-03]]引入"带外域"与"杂散域"的空间化频域划分概念。
- **1.147 指配频段**：其带宽 = 必要带宽 + 2×频率容限绝对值；涉及空间电台时还需加上2倍最大多普勒频移，考虑卫星通信的特殊性。
- **1.152-1.153 必要带宽 vs 占用带宽**：必要带宽是恰好保证规定信息传输速率和质量的带宽；占用带宽是以β/2=0.5%功率百分比为界的统计带宽，二者分别服务于频谱规划与管理验证。
- **1.156 功率表示体系统一**：定义峰包功率(PX/pX)、平均功率(PY/pY)、载波功率(PZ/pZ)，大写P为dB表示，小写p为瓦特表示，适用于所有发射类别。
- **1.160 天线增益三类基准**：全向天线(Gi)、半波振子(Gd)、短垂直天线(Gv)，分别对应1.161 e.i.r.p.、1.162 e.r.p.、1.163 e.m.r.p.三种等效辐射功率。
- **多语文术语对照表**（1.144/1.145/1.146对应中文/法文/英文/西班牙文/阿拉伯文/俄文六语）：确保带外发射、杂散发射、无用发射三个关键概念在国际协调中无歧义。

## 涉及概念

- 辐射（Radiation）、发射（Emission）、发射类别（Class of Emission）
- 单边带发射（SSB）：全载波/减载波/抑制载波三种子类型
- 带外发射（Out-of-band Emission）、杂散发射（Spurious Emission）、无用发射（Unwanted Emissions）
- 带外域（Out-of-band Domain）、杂散域（Spurious Domain）——[[concepts/radio_rules/wrc-03|WRC-03]]概念
- 指配频段（Assigned Frequency Band）、指配频率（Assigned Frequency）、特征频率（Characteristic Frequency）、基准频率（Reference Frequency）
- 频率容限（Frequency Tolerance）、必要带宽（Necessary Bandwidth）、占用带宽（Occupied Bandwidth）
- 右旋/左旋极化波（Right-hand/Left-hand Polarized Wave）
- 峰包功率（Peak Envelope Power）、平均功率（Mean Power）、载波功率（Carrier Power）
- 天线增益（Antenna Gain）：全向增益(Gi)、半波振子增益(Gd)、短垂直天线增益(Gv)
- 等效全向辐射功率（e.i.r.p.）、有效辐射功率（e.r.p.）、有效单极辐射功率（e.m.r.p.）
- 对流层散射（Tropospheric Scatter）、电离层散射（Ionospheric Scatter）
- 多普勒频移（在指配频段定义中涉及）
