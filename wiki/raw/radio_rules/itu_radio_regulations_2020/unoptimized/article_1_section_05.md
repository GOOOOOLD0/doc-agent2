# [[concepts/radio_rules/article_1|第1条]] — 第05节

## 概念定义

来源于《无线电规则：2020年第1卷——条款》（2020）第15页 至 第32页。

第V节（1.116–1.136）定义了21个无线电通信操作术语，涵盖通信类型（公众通信/电报/电话/传真/电视）、传输模式（单工/双工/半双工）、接收方式（个体/集体接收）、遥测/遥令/跟踪等空间操作技术以及调制技术（移频电报），并附有两条脚注对书面文件的永久性和双工操作的频率使用做补充说明，是第III节业务定义和第IV节台站定义在实际操作层面的术语规范。

## 核心内容

第V节 - 操作术语

| 条款 | 定义 |
|------|------|
| 1.116 | 公众通信：各电信局和电台由于其为公众服务的性质而必须受理并传递的任何电信（《组织法》）。 |
| 1.117 | 电报技术1：一种目的在于将所发送的信息在到达时作为书面文件而予以登记的电信方式，所发送的信息有时可以以其他形式表示，亦可以被存储起来供以后使用 （《组织法》第1016款）。 |
| 1.118 | 电报：用电报技术传输并向收报人投递的书面材料。除非另有规定，这一术语亦包括无线电报在内（《组织法》）。 在本定义中电报技术这一术语的一般含义与《组织法》中规定的相同。 |
| 1.119 | 无线电报：发自或发往移动电台或移动地球站的电报，其全部或部分传输路由为移动业务或卫星移动业务的无线电通信通路。 |
| 1.120 | 无线电用户电报呼叫：发自或发往移动电台或移动地球站的用户电报呼叫，其全部或部分传输路由为移动业务或卫星移动业务的无线电通信通路。 |
| 1.121 | 移频电报技术：电报信号控制载波频率在预定的范围之内变化的调频电报技术。 |
| 1.122 | 传真：传输带有或不带有中间色调固定图像，使其以一种可以长久保存方式重现的一种电报技术方式。 |
| 1.123 | 电话技术：一种主要目的在于交换话音信息的电信方式（《组织法》第 1017款）。 |
| 1.124 | 无线电话呼叫：发自或发往移动电台或移动地球站的电话呼叫，其全部或部分传输路由为移动业务或卫星移动业务的无线电通信通路。 |
| 1.125 | 单工操作：可在一条电信通路的每个方向上交替进行传输的一种操作方法，例如人工控制2。 |
| 1.126 | 双工操作：可在一条电信通路的两个方向上同时进行传输的一种操作方法2。 |
| 1.127 | 半双工操作：电路的一端用单工操作，另一端用双工操作的一种方法2。 |
| 1.128 | 电视：传输静止或活动景物的瞬间图像的一种电信方式。 |
| 1.129 | 个体接收（用于卫星广播业务）：利用简单家庭用设备，特别是配有小型天线的家庭用设备来接收卫星广播业务中的空间电台的发射。 |
| 1.130 | 集体接收（用于卫星广播业务）：利用有时可能是复杂的且其天线大于个体接收天线的接收设备来接收卫星广播业务中的空间电台的发射，以供：  同一地点内的一般公众群体利用；或通过分配系统覆盖一个有限地区。 |
| 1.131 | 遥测技术：利用电信在离测量仪器有一定距离的地方，自动地显示或登记测量结果的技术。 |
| 1.132 | 无线电遥测技术：使用无线电波的遥测技术。 |
| 1.133 | 空间遥测技术：空间电台利用遥测技术发送空间飞行器上所测得的结果， 包括与空间飞行器本身运行有关的测量结果。 |
| 1.134 | 遥令：为启动、更改或终止远距离设备的运行而利用电信传送信号。 |
| 1.135 | 空间遥令：为启动、更改或终止相关空间物体上，包括空间电台上设备的运行而利用无线电通信向空间电台传送信号。 |
| 1.136 | 空间跟踪：利用除一次雷达以外的无线电测定方法，测定空间物体的轨道、速度或瞬间位置以跟踪该物体的运动。 |

> **注：** 1 1.117.1 书面文件以永久方式登记信息，因而可以存档和查阅；它可以是手写的或书面印刷的材料，亦可以是静止的图像。
> **注：** 2 1.125.1、1.126.1和1.127.1 一般说来，双工操作和半双工操作在无线电通信中需要两个频率；单工操作用一个或两个频率均可。

## 关键条款 / 关键观点

1. **公众通信的强制性服务原则（1.116）**：公众通信是各电信局和电台"由于其为公众服务的性质而必须受理并传递的任何电信"，引用《组织法》，确立了公共服务义务。这是电信普遍服务原则在无线电领域的具体体现。

2. **电报技术的书面文件本质（1.117及脚注1）**：电报技术以"到达时作为书面文件而予以登记"为核心特征，脚注1补充说明"书面文件以永久方式登记信息，因而可以存档和查阅"，可涵盖手写、印刷和静止图像。这一特点将电报与电话（话音）和电视（图像）在操作层面明确区分。

3. **无线电报/无线电话的移动业务限定（1.119/1.124）**：无线电报和无线电话呼叫均定义为"发自或发往移动电台或移动地球站"且"全部或部分传输路由为移动业务或卫星移动业务的无线电通信通路"，这意味着固定业务中的电报/电话不适用这两个术语。这一限定影响计费、路由选择和业务统计。

4. **单工/双工/半双工的操作模式定义（1.125–1.127及脚注2）**：三条定义构成完整的操作模式体系。脚注2明确"双工和半双工在无线电通信中通常需要两个频率，单工可用一个或两个频率"，这一附带说明实质上是对频率指配的技术指引。

5. **卫星广播接收的个体/集体二分（1.129–1.130）**：个体接收使用简单家庭设备（小型天线），集体接收使用复杂设备（较大天线）并通过分配系统覆盖有限区域。这一区分直接影响卫星广播的功率通量密度限制和频率规划（如Appendix 30/30A）。

6. **遥测/遥令/跟踪的空间操作三件套（1.131–1.136）**：遥测（从空间飞行器获取测量数据）、遥令（向空间电台发送控制信号）、空间跟踪（测定轨道/速度/位置）构成空间操作业务的核心功能集合，是航天任务测控通信的术语基础。

7. **移频电报技术（1.121）**：作为独立的调制技术定义出现在操作术语中（而非在[[concepts/radio_rules/article_2|第2条]]的技术术语中），说明在2020版规则中，传统电报技术仍被视为重要的操作模式而非纯技术问题。

## 涉及概念

- **公众通信**：各电台因公共服务性质而必须受理和传递的电信（1.116），引用《组织法》。
- **电报技术 / 电报 / 无线电报**：电报技术以书面文件的永久登记为核心（1.117），电报为通过电报技术传输和投递的书面材料（1.118），无线电报特指经由移动业务或卫星移动业务传输的电报（1.119）。
- **无线电用户电报呼叫（1.120）**：经由移动/卫星移动业务的用户电报呼叫。
- **移频电报技术（1.121）**：电报信号通过载波频率的预定变化实现调频传输的技术。
- **传真（1.122）**：以永久保存方式重现固定图像的电报技术方式，可含或不含中间色调。
- **电话技术 / 无线电话呼叫**：以交换话音信息为目的（1.123），无线电话特指经由移动/卫星移动业务的话音呼叫（1.124）。
- **单工 / 双工 / 半双工操作**：单工为交替传输（1.125），双工为同时双向（1.126），半双工为一端单工一端双工（1.127）。脚注2说明双工通常需两个频率。
- **电视（1.128）**：传输静止或活动景物瞬间图像的电信方式。
- **个体接收 / 集体接收**：卫星广播的两种接收模式（1.129/1.130），个体用简单家用设备，集体用较复杂设备并可覆盖分配系统。
- **遥测技术 / 无线电遥测 / 空间遥测**：从远距离自动显示测量结果（1.131/1.132），空间遥测特指空间飞行器上的测量结果传输（1.133）。
- **遥令 / 空间遥令**：远程控制信号的传送（1.134），空间遥令针对空间电台（1.135）。
- **空间跟踪（1.136）**：利用非一次雷达的无线电测定方法跟踪空间物体运动。
