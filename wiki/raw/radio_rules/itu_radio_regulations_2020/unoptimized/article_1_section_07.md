# [[concepts/radio_rules/article_1|第1条]] — 第07节

## 概念定义

来源于《无线电规则：2020年第1卷——条款》（2020）第15页 至 第32页。

[[concepts/radio_rules/article_1|第1条]]第7节（条款1.166-1.176）定义了无线电频率共用中的干扰分类与管理体系，包括干扰的基本定义、三级干扰容忍度标准（可允许干扰/可接受干扰/有害干扰）、保护率、以及卫星地球站与地面电台频率协调的空间几何框架（协调区/协调等值线/协调距离），并补充了等效卫星链路噪声温度及可调卫星波束瞄准区等卫星操作概念，构成国际频率协调与干扰管理的术语基础。

## 核心内容

第VII节 - 频率共用

| 条款 | 定义 |
|------|------|
| 1.166 | 干扰：由于某种发射、辐射、感应或其组合所产生的无用能量对无线电通信系统的接收产生的影响，这种影响的后果表现为性能下降、误解或信息遗漏，如不存在这种无用能量，则此后果可以避免。 |
| 1.167 | 可允许干扰3：观测到的或预测的干扰，该干扰符合本规则或ITU-R建议书或本规则规定的特别协议载明的干扰允许值和共用的定量标准。 |
| 1.168 | 可接受干扰3：其电平高于规定的可允许干扰电平，但经两个或两个以上主管部门协商同意，并且不损害其他主管部门的利益的干扰。 |
| 1.169 | 有害干扰：危及无线电导航或其他安全业务的运行，或严重损害、阻碍、 或一再阻断按照《无线电规则》开展的无线电通信业务的干扰（《组织法》）。 |
| 1.170 | 保护率（R.F.）：为让接收机输出端的有用信号达到规定的接收质量，在规定条件下确定的接收机输入端有用信号与无用信号的最小比值，通常以分贝表示。 |
| 1.171 | 协调区：与地面电台共用同一频段的地球站周围的地区，或与接收地球站共用相同双向划分频段的发射地球站周围的地区，用于确定是否需要协调，在该地区以外不会超过可允许干扰电平，因此不需要进行协调。（[[concepts/radio_rules/wrc-20|WRC-20]]00） |
| 1.172 | 协调等值线：环绕协调区的线。 |
| 1.173 | 协调距离：在给定方位上从与地面电台共用相同频段的地球站起算的距离，或从与接收地球站共用双向划分频段的发射地球站起算的距离，用于确定是否需要协调，在该距离以外不会超过可允许干扰电平，因此不需要进行协调。（[[concepts/radio_rules/wrc-20|WRC-20]]00） |
| 1.174 | 等效卫星链路噪声温度：折算到地球站接收天线输出端的噪声温度，它对应于在卫星链路输出端产生全部所测噪声的射频噪声功率，但来自使用其他卫星的卫星链路的干扰和来自地面系统的干扰所造成的噪声除外。 |
| 1.175 | （可调卫星波束的）有效瞄准区：用一个可调卫星波束瞄准线瞄准到的地球表面的一个地区。 单个可调卫星波束可能会瞄准到一个以上互不相连的有效瞄准区。 |
| 1.176 | （可调卫星波束的）有效天线增益等值线：可调卫星波束瞄准线沿着有效瞄准区边缘移动所产生的天线增益等值线的包络线。 |

> **注：** 3 1.167.1和1.168.1 术语可允许干扰及可接受干扰用于主管部门之间频率指配的协调。

## 关键条款 / 关键观点

- **1.166 干扰的广义定义**：涵盖发射、辐射、感应或其组合产生的无用能量，后果表现为性能下降、误解或信息遗漏——强调"若无此无用能量则可避免"，确立了因果判定标准。
- **1.167-1.169 三级干扰容忍度框架**：可允许干扰（符合规则/建议书/特别协议的定量标准，是客观技术阈值）→ 可接受干扰（经两方或多方主管部门协商同意且不损害第三方，是主观协商结果，电平可高于可允许干扰）→ 有害干扰（危及安全业务或严重损害/阻碍/一再阻断合规通信，是绝对禁止红线，源自《组织法》）。
- **1.168 可接受干扰的重要注释**：经协商同意可容忍超过可允许电平的干扰，但不能损害其他主管部门——体现了国际频率协调中"双边协商可超越技术标准，但不得外溢影响第三方"的基本原则。
- **1.170 保护率（R.F.）**：接收机输入端有用信号/无用信号的最小比值，以分贝表示，是确定协调阈值的核心参数。
- **1.171-1.173 协调空间框架**：协调区（地球站周围区域）→ 协调等值线（边界线）→ 协调距离（某方位上从地球站起算的距离），三者层层递进，区域外不超过可允许干扰电平则无需协调（[[concepts/radio_rules/wrc-20|WRC-20]]00修订）。
- **1.174 等效卫星链路噪声温度**：折算到地球站接收天线输出端的噪声温度，排除其他卫星链路和地面系统干扰，专门用于评估单一卫星链路的固有噪声性能。
- **1.175-1.176 可调卫星波束概念**：有效瞄准区（波束瞄准线可覆盖的地球表面区域，可多个不连续区域）+ 有效天线增益等值线（瞄准线沿区域边缘移动形成的包络线），为灵活波束卫星的频率协调提供空间边界定义。

## 涉及概念

- 干扰（Interference）：无用能量对无线电通信接收的影响
- 可允许干扰（Permissible Interference）：符合规则/建议书/协议的干扰定量标准
- 可接受干扰（Accepted Interference）：经主管部门协商同意且不损害第三方的超标准干扰
- 有害干扰（Harmful Interference）：危及安全业务或严重阻碍合规通信的干扰，源于《组织法》定义
- 保护率（Protection Ratio, R.F.）：接收机输入端有用/无用信号最小比值
- 协调区（Coordination Area）、协调等值线（Coordination Contour）、协调距离（Coordination Distance）
- 等效卫星链路噪声温度（Equivalent Satellite Link Noise Temperature）
- 可调卫星波束（Steerable Satellite Beam）
- 有效瞄准区（Effective Boresight Area）、有效天线增益等值线（Effective Antenna Gain Contour）
- 双向划分频段（Bidirectional Frequency Allocations）
