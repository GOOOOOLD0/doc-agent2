# [[concepts/radio_rules/article_1|第1条]] — 第08节

## 概念定义

来源于《无线电规则：2020年第1卷——条款》（2020）第15页 至 第32页。

[[concepts/radio_rules/article_1|第1条]]第8节（条款1.177-1.191）定义了空间无线电通信的核心技术术语体系，涵盖深空边界（2×10⁶ km）、空间飞行器与卫星类型（有源/反射）、遥感器分类（有源/无源）、轨道参数（倾角/周期/远地点/近地点）、地球同步/对地静止卫星与轨道的关键区别，以及可调卫星波束概念，为卫星业务协调与频率管理提供统一的空间术语基础。

## 核心内容

第VIII节 - 空间技术术语

| 条款 | 定义 |
|------|------|
| 1.177 | 深空：离地球的距离等于或大于2 × 106 km的空间。 |
| 1.178 | 空间飞行器：拟飞往地球大气层主要部分以外的人造飞行器。 |
| 1.179 | 卫星：围绕着一个质量远大于己的物体旋转的物体，其运行主要并恒久地由前者的引力决定。 |
| 1.180 | 有源卫星：载有用于发射或转发无线电通信信号的电台的卫星。 |
| 1.181 | 反射卫星：用于反射无线电通信信号的卫星。 |
| 1.182 | 有源遥感器：用于卫星地球探测业务或空间研究业务的一种测量仪器，通过它发射和接收无线电波以获得信息。 |
| 1.183 | 无源遥感器：用于卫星地球探测业务或空间研究业务的一种测量仪器，通过它接收自然界发出的无线电波以获得信息。 |
| 1.184 | 轨道：在自然力（主要是重力）的作用下，卫星或其他空间物体的质量中心所描绘的相对于某指定参照系的轨迹。 |
| 1.185 | （地球卫星的）轨道的倾角：以轨道的升交点为顶点，沿地球赤道平面按逆时针方向算起的轨道所在平面与地球赤道平面的夹角，以度为单位，范围0°至180°。 （[[concepts/radio_rules/wrc-20|WRC-20]]00） |
| 1.186 | （卫星的）周期：一个卫星连续两次经过其轨道上的某一特征点的间隔时间。 |
| 1.187 | 远地点的高度或近地点的高度：远地点或近地点相对于一个用以代表地球表面的规定基准面上方的高度。 |
| 1.188 | 地球同步卫星：运转周期等于地球自转周期的地球卫星。 |
| 1.189 | 对地静止卫星：其圆形且顺行轨道位于地球赤道平面上，并对地球保持相对静止的地球同步卫星；广义而言，指对地球保持大致相对静止的地球同步卫星。（[[concepts/radio_rules/wrc-03|WRC-03]]） |
| 1.190 | 对地静止卫星轨道：其圆形且顺行轨道位于地球赤道平面上的地球同步卫星的轨道。 |
| 1.191 | 可调卫星波束：能重新进行瞄准的卫星天线波束。 |

## 关键条款 / 关键观点

- **1.177 深空边界**：距离地球≥2×10⁶ km（约200万公里，远超月球轨道约38.4万公里），是划分深空业务与近地空间业务的法定边界，影响频率划分和功率限制的不同规定。
- **1.179 卫星的定义**：强调"主要并恒久由前者引力决定"——自然卫星与人工卫星均适用此定义，但无线电规则语境下关注的是人造卫星。
- **1.180-1.181 有源卫星 vs 反射卫星**：有源卫星载有发射/转发无线电通信信号的电台（如通信广播卫星），反射卫星仅被动反射信号（如早期无源通信卫星Echo），两类卫星适用不同的操作规则。
- **1.182-1.183 遥感器分类**：有源遥感器主动发射并接收无线电波获取信息（如合成孔径雷达SAR），无源遥感器仅被动接收自然界无线电波（如微波辐射计），二者对应的业务划分和频率分配不同。
- **1.185 轨道倾角定义**：以升交点为顶点沿赤道平面逆时针计算（0°-180°），按[[concepts/radio_rules/wrc-20|WRC-20]]00修订，是区分顺行轨道（0°-90°）、逆行轨道（90°-180°）和极地轨道（≈90°）的关键参数。
- **1.188-1.190 地球同步卫星 vs 对地静止卫星 vs 对地静止卫星轨道（GSO）的核心辨析**：地球同步卫星（周期=地球自转周期，轨道不一定在赤道面上）→ 对地静止卫星（圆形+顺行+赤道面，对地球相对静止，[[concepts/radio_rules/wrc-03|WRC-03]]放宽为"大致"相对静止）→ GSO（对地静止卫星的唯一轨道，是有限自然资源），三者层层递进，GSO作为稀缺自然资源的定性直接影响其国际使用权的协调分配机制。
- **1.191 可调卫星波束**：能重新瞄准的卫星天线波束，为本节与第7节1.175/1.176可调波束瞄准概念的术语衔接。

## 涉及概念

- 深空（Deep Space）：≥2×10⁶ km的地球距离
- 空间飞行器（Spacecraft）：飞往地球大气层主要部分以外的人造飞行器
- 卫星（Satellite）：围绕质量远大于己的物体旋转、运行由前者引力决定的物体
- 有源卫星（Active Satellite）：载有用于发射/转发信号的电台
- 反射卫星（Reflecting Satellite）：仅用于反射无线电通信信号
- 有源遥感器（Active Sensor）：发射并接收无线电波获取信息（如SAR）
- 无源遥感器（Passive Sensor）：仅接收自然界无线电波获取信息（如辐射计）
- 轨道（Orbit）、轨道倾角（Inclination of an Orbit）：0°-180°，升交点起逆时针
- 卫星周期（Period of a Satellite）、远地点/近地点高度（Altitude of Apogee/Perigee）
- 地球同步卫星（Geosynchronous Satellite）：周期=地球自转周期
- 对地静止卫星（Geostationary Satellite）：圆形+顺行+赤道面+相对静止（[[concepts/radio_rules/wrc-03|WRC-03]]）
- 对地静止卫星轨道（Geostationary-Satellite Orbit, GSO）：有限自然资源
- 可调卫星波束（Steerable Satellite Beam）

## 争议或待核查问题

- 深空边界2×10⁶ km的设定依据是什么？是否基于地球引力影响球（Hill Sphere）或日地拉格朗日点的考虑？
- [[concepts/radio_rules/wrc-03|WRC-03]]将1.189定义从"保持相对静止"改为"保持大致相对静止"——"大致"的具体技术判断标准是什么？是否有ITU-R建议书进一步量化？
- 反射卫星（1.181）在现代卫星通信中是否还有实际应用？规则保留此定义是否有历史遗产考量？
- 轨道倾角1.185定义中"沿地球赤道平面按逆时针方向"的参照系在近赤道轨道（倾角接近0°或180°）时是否存在歧义？
