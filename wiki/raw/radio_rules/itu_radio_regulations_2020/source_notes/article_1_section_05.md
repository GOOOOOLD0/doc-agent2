# 第1条 — 第5节

## 一句话总结

第V节（1.116–1.136）定义了21个无线电通信操作术语，涵盖通信类型（公众通信/电报/电话/传真/电视）、传输模式（单工/双工/半双工）、接收方式（个体/集体接收）、遥测/遥令/跟踪等空间操作技术以及调制技术（移频电报），并附有两条脚注对书面文件的永久性和双工操作的频率使用做补充说明，是第III节业务定义和第IV节台站定义在实际操作层面的术语规范。

## 关键条款 / 关键观点

1. **公众通信的强制性服务原则（1.116）**：公众通信是各电信局和电台"由于其为公众服务的性质而必须受理并传递的任何电信"，引用《组织法》，确立了公共服务义务。这是电信普遍服务原则在无线电领域的具体体现。

2. **电报技术的书面文件本质（1.117及脚注1）**：电报技术以"到达时作为书面文件而予以登记"为核心特征，脚注1补充说明"书面文件以永久方式登记信息，因而可以存档和查阅"，可涵盖手写、印刷和静止图像。这一特点将电报与电话（话音）和电视（图像）在操作层面明确区分。

3. **无线电报/无线电话的移动业务限定（1.119/1.124）**：无线电报和无线电话呼叫均定义为"发自或发往移动电台或移动地球站"且"全部或部分传输路由为移动业务或卫星移动业务的无线电通信通路"，这意味着固定业务中的电报/电话不适用这两个术语。这一限定影响计费、路由选择和业务统计。

4. **单工/双工/半双工的操作模式定义（1.125–1.127及脚注2）**：三条定义构成完整的操作模式体系。脚注2明确"双工和半双工在无线电通信中通常需要两个频率，单工可用一个或两个频率"，这一附带说明实质上是对频率指配的技术指引。

5. **卫星广播接收的个体/集体二分（1.129–1.130）**：个体接收使用简单家庭设备（小型天线），集体接收使用复杂设备（较大天线）并通过分配系统覆盖有限区域。这一区分直接影响卫星广播的功率通量密度限制和频率规划（如Appendix 30/30A）。

6. **遥测/遥令/跟踪的空间操作三件套（1.131–1.136）**：遥测（从空间飞行器获取测量数据）、遥令（向空间电台发送控制信号）、空间跟踪（测定轨道/速度/位置）构成空间操作业务的核心功能集合，是航天任务测控通信的术语基础。

7. **移频电报技术（1.121）**：作为独立的调制技术定义出现在操作术语中（而非在第2条的技术术语中），说明在2020版规则中，传统电报技术仍被视为重要的操作模式而非纯技术问题。

## 涉及概念

- **公众通信**：各电台因公共服务性质而必须受理和传递的电信（1.116），引用《组织法》。
- **电报技术 / 电报 / 无线电报**：电报技术以书面文件的永久登记为核心（1.117），电报为通过电报技术传输和投递的书面材料（1.118），无线电报特指经由移动业务或卫星移动业务传输的电报（1.119）。
- **无线电用户电报呼叫（1.120）**：经由移动/卫星移动业务的用户电报呼叫。
- **移频电报技术（1.121）**：电报信号通过载波频率的预定变化实现调频传输的技术。
- **传真（1.122）**：以永久保存方式重现固定图像的电报技术方式，可含或不含中间色调。
- **电话技术 / 无线电话呼叫**：以交换话音信息为目的（1.123），无线电话特指经由移动/卫星移动业务的话音呼叫（1.124）。
- **单工 / 双工 / 半双工操作**：单工为交替传输（1.125），双工为同时双向（1.126），半双工为一端单工一端双工（1.127）。脚注2说明双工通常需两个频率。
- **电视（1.128）**：传输静止或活动景物瞬间图像的电信方式。
- **个体接收 / 集体接收**：卫星广播的两种接收模式（1.129/1.130），个体用简单家用设备，集体用较复杂设备并可覆盖分配系统。
- **遥测技术 / 无线电遥测 / 空间遥测**：从远距离自动显示测量结果（1.131/1.132），空间遥测特指空间飞行器上的测量结果传输（1.133）。
- **遥令 / 空间遥令**：远程控制信号的传送（1.134），空间遥令针对空间电台（1.135）。
- **空间跟踪（1.136）**：利用非一次雷达的无线电测定方法跟踪空间物体运动。

## 涉及机构

- **国际电信联盟（ITU）**：操作术语的维护机构，电信标准化部门（ITU-T）负责电报、电话、传真等固定电信术语，无线电通信部门（ITU-R）负责无线电特有操作术语。
- **国际海事组织（IMO）**：无线电报/无线电话呼叫（1.119/1.124）在GMDSS中作为遇险通信的操作模式被引用，与IMO的通信标准和程序相关。
- **国际民用航空组织（ICAO）**：航空移动业务中的操作模式（单工/双工）受ICAO航空通信程序（Pan 10 Vol.II）规范。
- **各国航天机构**：空间遥测/遥令/跟踪（1.133/1.135/1.136）是CCSDS（空间数据系统咨询委员会）和各国航天测控网的操作基础。
- **各国电信运营商**：公众通信（1.116）的义务主体，需要确保遵守ITU的操作术语规范进行互联互通。

## 可能影响

1. **传统电报术语的现代适用性**：电报（1.118）、无线电报（1.119）、移频电报（1.121）和用户电报呼叫（1.120）在现代全IP通信环境中已几乎不再使用，但这些定义在遇险与安全通信（如GMDSS中的NBDP窄带直接打印）中仍有操作意义——若这些术语被废止，需要确保替代术语覆盖所有遗留场景。

2. **"无线电话"定义的移动限定可能引发混淆**：无线电话呼叫（1.124）的移动业务限定意味着固定电话/卫星固定业务中的话音呼叫在严格意义上不适用该术语，但实际使用中常被泛化。这在多业务融合的现代网络中可能造成术语不一致。

3. **个体/集体接收对卫星广播的规制影响**：个体接收（1.129）和集体接收（1.130）的定义直接影响WRC卫星广播规划（BSS Plan）中的等效保护功率通量密度（epfd）计算。如果ITU调整这两个定义的边界，将直接影响现有BSS频率规划。

4. **空间跟踪的定义排除了雷达**：空间跟踪（1.136）明确排除一次雷达，仅用其他无线电测定方法。这意味着按ITU定义，雷达跟踪（如火控雷达）不属于"空间跟踪"范畴，对军事航天活动的术语适用有重要影响。

5. **单工/双工定义对频率规划的技术约束**：脚注2明确双工和半双工通常需两个频率——这在实际频谱管理中转化为"成对频率"的分配原则。随着TDD（时分双工）技术在4G/5G中的广泛使用（一个频率实现双工），该脚注是否需要更新值得关注。

## 待核查问题

1. 电报/无线电报/用户电报（1.118–1.120）在WRC-19或WRC-23是否有废止或修订的提案？鉴于GMDSS现代化正逐步淘汰NBDP，这些定义是否有更新的时间表？

2. 脚注1和脚注2（关于书面文件和双工操作）是2020版原文还是WRC-19新增的？需核实脚注的引入历史。

3. 个体接收（1.129）中"简单家庭用设备"和"小型天线"的具体技术指标（如天线直径、G/T值）是否有ITU-R建议书（如BO系列）进一步细化？还是完全留给各国自行解释？

4. 空间跟踪（1.136）"除一次雷达以外的无线电测定方法"——二次雷达是否包含在内？这个排除条款的实际意图是什么？

5. "传真"（1.122）的定义涵盖"带或不带中间色调的固定图像"，在现代数字图像传输（JPEG/MJPEG通过移动网络）中，该定义是否仍然适用？ITU-T和ITU-R之间对此是否有协调？
