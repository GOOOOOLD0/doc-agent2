# 第1条 — 第4节

## 一句话总结

第IV节（1.61–1.115）定义了55种以上的无线电台站与系统类型，从最基本的"电台"概念出发，按物理位置（地面/地球站/空间）、移动状态（固定/移动/陆地）、行业领域（水上/航空）和技术功能（雷达/导航/系统）多维度构建了完整的台站分类体系，是第III节业务定义在物理基础设施层面的具体落地，也是频率指配、台站执照管理和国际协调的技术基础。

## 关键条款 / 关键观点

1. **电台的统一定义（1.61）**：电台是"一台或多台发信机或收信机的组合（包括附属设备）"，按常设或临时运营分类。这一简洁定义将所有无线电发射/接收设施纳入规范范围，是后续所有台站定义的逻辑起点。

2. **地面/地球站/空间的三层物理架构（1.62–1.64）**：地面电台（1.62）→地球站（1.63，地表或大气层内）→空间电台（1.64，大气层外），构成从地面到空间的完整物理维度。地球站的特殊性在于它既可与空间电台通信，也可通过反射卫星与其他地球站通信。

3. **高空平流层电台（1.66A）**：WRC-19或此前WRC新增的定义，位于20–50 km高度、相对地面固定点的物体上，填补了传统地面电台与空间电台之间的中间层，对高空平台（HAPS）的部署具有重要法规意义。

4. **移动/陆地电台的对称结构**：移动电台（1.67）在移动中使用，陆地电台（1.69）不供移动中使用——两者构成移动业务的双端。卫星版本（1.68/1.70）延续同一逻辑。"基地电台"（1.71）是陆地电台的子类，专用于陆地移动业务。

5. **水上电台的完整生态（1.75–1.80）**：海岸电台（1.75）→船舶电台（1.77）→船上通信电台（1.79）→港口电台（1.80），覆盖了从公海到港口的水上通信全场景。海岸地球站（1.76）与船舶地球站（1.78）提供卫星版本的对应。

6. **雷达系统的三级定义（1.100–1.103）**：雷达（1.100，通用）→一次雷达（1.101，反射信号）→二次雷达（1.102，重发信号）→雷达信标（1.103，固定导航标志附带的应答器），构成从原理到设备的完整定义链。一次/二次的区分对航空管制雷达（SSR）和海上导航雷达有直接技术影响。

7. **仪表着陆系统（ILS）的组件化定义（1.104–1.107）**：将ILS拆解为航向信标（水平引导）、下滑信标（垂直引导）和指点信标（位置标记）三个独立条款，反映了航空导航系统定义的精确性和对安全冗余的重视。

8. **空间系统的层级定义（1.110–1.115）**：空间系统（1.110）→卫星系统（1.111）→卫星网络（1.112）→卫星链路（1.113，单卫星）/多卫星链路（1.114）→馈线链路（1.115），构成从系统到链路的完整层级。馈线链路（1.115）将地球站到卫星之间的传输链路标准化，是卫星频率协调的核心概念。

## 涉及概念

- **电台（Station）**：发信机和/或收信机及其附属设备的组合（1.61），是所有具体台站的上位概念。
- **地面电台 / 地球站 / 空间电台**：按物理位置的三层分类（1.62–1.64），"除非另有说明，任何电台均指地面电台"确立了默认规则。
- **高空平流层电台（HAPS电台）**：20–50 km高空的准固定电台（1.66A），涉及平流层通信平台。
- **移动电台 / 移动地球站**：在移动中或非指定地点使用的电台（1.67/1.68）。
- **陆地电台 / 基地电台**：不供移动中使用的电台（1.69/1.71），基地电台是陆地移动业务的特定陆地电台。
- **海岸电台 / 船舶电台 / 港口电台**：水上移动业务的三类核心台站（1.75/1.77/1.80）。
- **航空电台 / 航空器电台**：航空移动业务的陆地端与机载端（1.81/1.83）。
- **应急示位无线电信标（EPIRB）**：地面版（1.93）与卫星版（1.94），用于搜索与救助。
- **雷达 / 一次雷达 / 二次雷达 / 雷达信标**：基于反射/重发信号的测定系统（1.100–1.103），二次雷达（SSR）是航空管制的核心技术。
- **仪表着陆系统（ILS）**：航向信标（1.105）、下滑信标（1.106）、指点信标（1.107）组成的精密进近系统。
- **无线电高空测候器（Radiosonde）**：自动发送气象数据的发信机（1.109），通常搭载于气球。
- **自适应系统（1.109A）**：根据频道质量自动改变无线电特性的系统，是认知无线电的法规基础。
- **卫星网络 / 卫星链路 / 馈线链路**：卫星系统的三个层级概念（1.112/1.113/1.115），馈线链路特指地球站与空间电台之间的传输链路。
- **多卫星链路（1.114）**：不经中间地球站、经多颗卫星的链路，涉及星间路由。

## 涉及机构

- **国际电信联盟（ITU）**：无线电规则局（BR）负责卫星网络的频率指配协调与登记，台站定义是BR日常工作（如MIFR登记、API审查）的基础。
- **国际民用航空组织（ICAO）**：ILS（1.104–1.107）和航空类台站（1.81–1.84）的定义与ICAO的空中导航标准（SARPs Annex 10）深度耦合。
- **国际海事组织（IMO）**：船舶电台（1.77）、EPIRB（1.93/1.94）和船舶应急发信机（1.99）是GMDSS的核心组成部分，IMO负责制定性能标准。
- **国际搜救卫星组织（Cospas-Sarsat）**：卫星EPIRB（1.94）的全球运行机构，负责极轨道和静止轨道搜救卫星系统的协调。
- **世界气象组织（WMO）**：无线电高空测候器（1.109）和气象辅助台站（1.108A/1.108B）与WMO的全球观测系统（GOS）协同运行。
- **各国通信/无线电管理机构**：负责台站执照发放、频率指配和国内台站数据库维护。

## 可能影响

1. **高空平流层电台（HAPS）的法规空白填补**：1.66A的定义为Google Loon、空客Zephyr等高空平台系统提供了明确的法规地位，使HAPS可在ITU框架下合法使用频谱，但也引发了对已有业务（特别是固定业务和卫星业务）的干扰协调问题。

2. **自适应系统的灰色地带**：1.109A的定义极为宽泛（"根据频道质量改变其无线电特性"），覆盖了从动态频率选择（DFS）到认知无线电的所有自适应技术，但缺乏具体的技术参数门槛，可能导致各国在认证和合规检查中的标准不一致。

3. **仪表着陆系统（ILS）定义的精确性影响航空安全**：ILS各组件（航向信标、下滑信标、指点信标）的独立定义意味着每个组件都需独立获得频率保护，任何对ILS保护标准的修订都可能影响机场周边的频谱使用。

4. **卫星网络与馈线链路的协调复杂性**：卫星网络（1.112）和馈线链路（1.115）的定义是ITU卫星频率协调（如Appendix 30/30A/30B）的核心依据。新卫星系统的申报必须精确匹配这些定义，否则可能被BR退回。

5. **EPIRB的双轨定义**：地面EPIRB（1.93，用于移动业务）与卫星EPIRB（1.94，卫星移动业务的地球站）分属不同定义，在GMDSS现代化进程中（如AIS-EPIRB的引入），需要明确新设备属于哪个定义范畴。

## 待核查问题

1. 1.66A（高空平流层电台）是由哪次WRC引入的？其频率使用限制在《无线电规则》第5条中如何规定？需核实具体频段归属。

2. 1.109A（自适应系统）是否已经引用了相关的ITU-R建议书（如SM系列）作为技术标准？如果没有，WRC-23是否有相关议题？

3. 实验电台（1.98）排除业余电台，但其与"空间研究业务"（1.55）和"空间操作业务"（1.23）的台站如何区分？实验电台的执照管理是否有专门的国际框架？

4. 船舶应急发信机（1.99）在GMDSS中已被卫星EPIRB（1.94）大幅替代，该定义是否在WRC层面讨论过更新或废止？

5. 仪表着陆系统（1.104–1.107）与新一代卫星导航着陆系统（GBAS/SBAS）在定义层面是否存在竞争或替代关系？ITU是否在更新这一定义以涵盖GNSS着陆技术？
