# [[concepts/radio_rules/article_1|第1条]] — 第07节

## 概念定义

来源于《无线电规则：2020年第1卷——条款》（2020）第15页 至 第32页。

本节定义无线电频率共用中的干扰分类与协调术语，涵盖干扰（可允许/可接受/有害三级分类）、保护率、协调区/等值线/距离、等效卫星链路噪声温度及可调卫星波束参数，共计11项定义（1.166–1.176），是卫星与地面业务频率共用协调的核心概念框架。

## 核心内容

第VII节 - 频率共用
| 条款 | 定义 |
|------|------|
| 1.166 | 干扰：由于某种发射、辐射、感应或其组合所产生的无用能量对无线电通信系统的接收产生的影响，这种影响的后果表现为性能下降、误解或信息遗漏，如不存在这种无用能量，则此后果可以避免。 |
| 1.167 | 可允许干扰：观测到的或预测的干扰，该干扰符合本规则或ITU-R建议书或本规则规定的特别协议载明的干扰允许值和共用的定量标准。 |
| 1.168 | 可接受干扰：其电平高于规定的可允许干扰电平，但经两个或两个以上主管部门协商同意，并且不损害其他主管部门的利益的干扰。 |
> **注3：** 1.167.1和1.168.1 术语可允许干扰及可接受干扰用于主管部门之间频率指配的协调。
| 条款 | 定义 |
|------|------|
| 1.169 | 有害干扰：危及无线电导航或其他安全业务的运行，或严重损害、阻碍、或一再阻断按照《无线电规则》开展的无线电通信业务的干扰（《组织法》）。 |
| 1.170 | 保护率（R.F.）：为让接收机输出端的有用信号达到规定的接收质量，在规定条件下确定的接收机输入端有用信号与无用信号的最小比值，通常以分贝表示。 |
| 1.171 | 协调区：与地面电台共用同一频段的地球站周围的地区，或与接收地球站共用相同双向划分频段的发射地球站周围的地区，用于确定是否需要协调，在该地区以外不会超过可允许干扰电平，因此不需要进行协调。（[[concepts/radio_rules/wrc-2000|WRC-2000]]） |
| 1.172 | 协调等值线：环绕协调区的线。 |
| 1.173 | 协调距离：在给定方位上从与地面电台共用相同频段的地球站起算的距离，或从与接收地球站共用双向划分频段的发射地球站起算的距离，用于确定是否需要协调，在该距离以外不会超过可允许干扰电平，因此不需要进行协调。（[[concepts/radio_rules/wrc-2000|WRC-2000]]） |
| 1.174 | 等效卫星链路噪声温度：折算到地球站接收天线输出端的噪声温度，它对应于在卫星链路输出端产生全部所测噪声的射频噪声功率，但来自使用其他卫星的卫星链路的干扰和来自地面系统的干扰所造成的噪声除外。 |
| 1.175 | （可调卫星波束的）有效瞄准区：用一个可调卫星波束瞄准线瞄准到的地球表面的一个地区。单个可调卫星波束可能会瞄准到一个以上互不相连的有效瞄准区。 |
| 1.176 | （可调卫星波束的）有效天线增益等值线：可调卫星波束瞄准线沿着有效瞄准区边缘移动所产生的天线增益等值线的包络线。 |

## 关键条款 / 关键观点

- **干扰的定义与后果**（1.166）：干扰是由无用能量（发射、辐射、感应或其组合）对无线电通信接收造成的影响，后果表现为性能下降、误解或信息遗漏。
- **干扰三级分类**（1.167–1.169）：可允许干扰（符合RR/ITU-R建议书/特别协议的定量标准）、可接受干扰（超过可允许电平但经相关主管部门协商同意且不损害第三方）、有害干扰（危及安全业务或严重损害/阻碍/阻断无线电通信）。注3明确前两者用于频率指配协调。有害干扰引用《组织法》。
- **保护率**（1.170）：接收机输入端有用信号与无用信号的最小比值（分贝），用于保证规定接收质量。
- **协调空间参数**（1.171–1.173）：协调区（地球站周围需协调的地区）、协调等值线（环绕协调区的线）、协调距离（给定方位上从地球站起算的距离）。标注[[concepts/radio_rules/wrc-20|WRC-20]]00修订。
- **卫星链路噪声**（1.174）：等效卫星链路噪声温度——折算到接收天线输出端的噪声温度，排除其他卫星链路和地面系统干扰。
- **可调波束参数**（1.175–1.176）：有效瞄准区（可调波束瞄准线覆盖的地表区域）和有效天线增益等值线（瞄准线沿有效瞄准区边缘移动的包络）。

## 涉及概念

- 干扰（interference）、可允许干扰（permissible interference）、可接受干扰（accepted interference）、有害干扰（harmful interference）
- 保护率（protection ratio, R.F.）
- 协调区（coordination area）、协调等值线（coordination contour）、协调距离（coordination distance）
- 等效卫星链路噪声温度（equivalent satellite link noise temperature）
- 有效瞄准区（effective boresight area）、有效天线增益等值线（effective antenna gain contour）
- 可调卫星波束（steerable satellite beam）

## 争议或待核查问题

- 第1.166条干扰定义涵盖"发射、辐射、感应或其组合"，与第VI节"发射/辐射"的严格区分形成对照——此处干扰来源更广泛
- 可允许干扰（1.167）和可接受干扰（1.168）的区别在于是否符合定量标准，实际协调中两者的界限可能模糊，依赖于主管部门之间的协商
- 协调区/等值线/距离（1.171–1.173）的具体计算方法由ITU-R建议书和《无线电规则》附录规定，定义本身不含计算方法
- 第1.175–1.176条可调波束的有效瞄准区/有效天线增益等值线概念较抽象，实际应用时需结合具体卫星天线方向图
