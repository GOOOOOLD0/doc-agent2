# [[concepts/radio_rules/article_3|第3条]]

## 概念定义

来源于《无线电规则：2020年第1卷——条款》（2020）第35页 至 第36页。

[[concepts/radio_rules/article_3|第3条]]（条款3.1-3.15）规定了无线电电台设备选择、性能与操作的技术总则，涵盖设备技术先进性义务（遵循最新ITU-R建议书）、频谱兼容设计原则、频率容限与无用发射的强制性限值（引用[[concepts/radio_rules/appendix_2|附录2]]和[[concepts/radio_rules/appendix_3|附录3]]）、带宽效率最大化原则（含带宽扩展技术与单边带技术）、接收机性能要求、主管部门监测校验职责，以及绝对禁止阻尼波发射，构成所有无线电业务发射电台必须遵守的技术底线规范。

第3条
电台的技术特性

| 条款 | 定义 |
|------|------|
| 3.1 | 电台所用设备的选择与性能以及电台的任何发射，应符合本规则的各项规定。 |
| 3.2 | 而且，为了尽量适合实际情况，应根据最近的，尤其是ITU-R建议书中所载明的技术进展，选择发射、接收和测量设备。 |
| 3.3 | 发射和接收设备拟用于频谱某一指定部分时，其设计应考虑频谱邻近部分或其他部分可能使用的发射和接收信设备的技术特性，条件是已采取技术上和经济上的一切合理措施，以减小后者发射设备的无用发射电平，以及降低后者接收设备对干扰的敏感性。 |
| 3.4 | 电台所用设备应按照相关ITU-R建议书，尽最大可能使用能够最有效地利用频谱的信号处理方法。这些方法包括某些带宽扩展技术，尤其是在调幅系统内使用单边带技术。 |
| 3.5 | 发射电台应符合附录2中规定的频率容限。 |
| 3.6 | 发射电台应符合附录3中规定的杂散域中无用发射的最大允许功率电平。 （WRC-12） |
| 3.7 | 发射电台须符合本规则中关于某些业务和某些发射类别的带外发射或带外域无用发射的最大允许功率电平的规定。如果没有这种最大允许功率电平，则发射电台应尽最大可能满足相关ITU-R建议书中规定的带外发射或带外域无用发射限制。（WRC-12） |
| 3.8 | 而且，应尽一切努力把频率容限和无用发射电平保持在技术状态和该项业务的性质所允许的最低值上。 |
| 3.9 | 发射带宽还应保证最有效地利用频谱；这通常要求把带宽保持在技术状态和该项业务的性质所允许的最低值上。附录1是确定必要带宽的导则。 |
| 3.10 | 采用带宽扩展技术时，应使用符合有效利用频谱的最小功率谱密度。 |
| 3.11 | 凡必须有效利用频谱时，任何业务所用接收机的频率容限应尽可能与该业务所用的发射机的频率容限一致，适当情况下尚应注意多普勒效应的影响。 |
| 3.12 | 接收电台应使用与相关的发射类别相适应的技术特性的设备，尤其是选择性应适当地顾及关于发射带宽的第3.9款。 |
| 3.13 | 接收机的性能特征应能充分保证该机不致受到由位于合理距离，且按本规则规定工作的发射机所产生的干扰的影响。 |
| 3.14 | 为了保证符合本规则的规定，各主管部门应对自己管辖范围内的电台的各种发射进行经常性校验。为此，必要时可以采用第16条指明的方法。所有测量技术与测量时间应尽实际可能遵照最新的ITU-R建议书。 |
| 3.15 | 一切电台都不得使用阻尼波发射。 |


## 关键条款 / 关键观点

- **3.1-3.2 设备合规与先进性义务**：设备选择、性能及任何发射均须符合规则规定（3.1），且应根据最新技术进展特别是ITU-R建议书选择设备（3.2）——体现了"合规+技术演进"双重约束。
- **3.3 频谱兼容设计原则**：设备设计应考虑频谱邻近部分或其他部分可能使用的设备技术特性，并采取一切技术和经济上合理的措施降低无用发射电平及接收机干扰敏感性——确立了"不干扰也不被干扰"的双向兼容理念，以"技术和经济上合理"为限度。
- **3.4 信号处理方法**：倡导使用最有效利用频谱的信号处理方法，特别指出带宽扩展技术和调幅系统中的单边带技术，推动了SSB在HF/VHF频段的全球采用。
- **3.5-3.7 频率容限与无用发射的三级强制性框架**：发射电台须符合[[concepts/radio_rules/appendix_2|附录2]]频率容限（3.5）、[[concepts/radio_rules/appendix_3|附录3]]杂散域无用发射最大允许功率电平（3.6，[[concepts/radio_rules/wrc-12|WRC-12]]修订）、以及特定业务/发射类别的带外域无用发射限值；无具体规定的则参照ITU-R建议书（3.7，[[concepts/radio_rules/wrc-12|WRC-12]]修订）。
- **3.8-3.10 频谱效率最大化原则**：频率容限和无用发射应保持在技术和业务性质所允许的最低值（3.8），发射带宽应保证最有效利用频谱并保持最低值（3.9，引用[[concepts/radio_rules/appendix_1|附录1]]为导则），带宽扩展技术应使用最小功率谱密度（3.10）。
- **3.11-3.13 接收机性能要求**：接收机频率容限应与发射机一致并考虑多普勒效应（3.11），选择性应适配发射带宽（3.12），抗干扰性能应能抵抗合理距离内合规发射机的干扰（3.13）——体现了发射/接收设备性能的对称性要求。
- **3.14 主管部门监测义务**：各主管部门应对辖区内电台发射进行经常性校验，必要时可采用[[concepts/radio_rules/article_16|第16条]]（干扰调查与监测）指明的测量方法，测量技术与时间应遵循最新ITU-R建议书。
- **3.15 阻尼波发射的绝对禁止**：一切电台不得使用阻尼波发射——此为无条件禁则，源于阻尼波发射的极宽频谱特性对频谱环境的严重污染，是无线电规则中少数没有任何例外或灵活性空间的条款之一。
