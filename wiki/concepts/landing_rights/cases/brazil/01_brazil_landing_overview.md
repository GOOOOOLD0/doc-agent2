# 巴西落地许可总览

## 1. 适用对象

本案例适用于外国卫星系统在巴西开展卫星通信业务的场景。

本文档处理的是外国卫星系统进入巴西市场的问题，即境外卫星运营商希望通过巴西本地公司或本地服务提供方向巴西市场提供卫星容量或终端用户服务。

## 2. 核心监管机构

巴西卫星通信和电信业务的核心监管机构为 Anatel。

Anatel 负责外国卫星开发权、电信服务授权、设备认证、站点许可等相关监管流程。

## 3. 核心准入要求

巴西不是所有项目都固定要求“两张核心牌照”，许可组合取决于实际业务：

1. 外国卫星通过 FSS、MSS 或 BSS 与巴西地球站通信并在巴西提供容量时，原则上需要卫星开发权；
2. 卫星容量供应本身不构成电信服务。仅向持牌电信或广播服务商或武装部队批发容量时，不应自动断言容量提供者还需终端服务授权；
3. 本地实体直接向终端用户提供电信服务时，通常还需取得相应电信服务授权并通知具体服务；
4. 依赖无线电频率的服务，还需落实频率授权或符合规则的卫星容量合同，并办理适用的电台许可。

因此，外国卫星开发权解决空间段和容量进入巴西的问题；服务授权解决谁可以向公众或特定用户提供电信服务的问题。两者可以同时出现，但不是无条件绑定。

## 4. 其他合规要求

除上述两类授权外，还需要关注：

1. 适用产品的合格评定和 Anatel homologation；
2. 发射型地球站、网关站和空间站许可，以及纯接收专业 FSS 站的登记；
3. 频率协调；
4. 相关费用；
5. 适用法律法规。

## 5. 巴西流程概括

### 5.1 仅批发卫星容量

1. 确定卫星、频段、覆盖和业务是否落入卫星开发权要求；
2. 指定符合要求的巴西法律代表；
3. 通过 SEI 提交外国卫星开发权申请；
4. 提交公司资格、原属国授权、简化技术方案、ITU filing、协调和代表指定材料；
5. 支付卫星开发权公开价格；
6. 空间段投入运行后办理空间站许可和 Fistel 事项；
7. 按实际部署处理发射型地球站许可和适用产品 homologation。

### 5.2 直接向终端用户提供服务

除上述事项外，通常还需要：

1. 由合格巴西主体取得集体利益或限制利益服务授权；
2. 在 Mosaico 等系统通知具体服务；
3. 根据 SCM、卫星 SMP、SLP 或其他实际服务类别满足专项要求；
4. 完成用户侧和网络侧适用设备、频率和电台许可；
5. 在全部相关前置条件满足后开展商业运营。

SBH 和 SBS 的双主体结构只是 Spacesail 报告提出的项目设计，不是法规要求所有外国卫星项目必须设立两个独立法人。

## 6. 对其他国家分析的启发

分析其他国家时，不应直接套用巴西流程，而应将巴西流程作为检查清单。

对于任何目标国家，至少需要确认：

1. 是否需要外国卫星准入或落地权；
2. 是否需要本地公司或本地代表；
3. 是否需要面向终端用户的电信服务许可；
4. 是否需要频率使用许可或频率协调；
5. 是否需要设备认证；
6. 是否需要地面站、网关站或用户终端许可；
7. 是否有费用、有效期、续期和监管报告要求。

## 8. 结论状态

### 8.1 已确认

1. 巴西存在独立的卫星开发权制度；
2. 卫星容量供应本身不构成电信服务；
3. 外国卫星需要符合要求的巴西法律代表；
4. 直接提供电信服务的巴西主体需要相应服务授权和具体服务通知；
5. 受监管产品、发射型地球站和空间站分别存在认证或许可要求；
6. 已公开确认卫星开发权、集体利益服务授权和空间站的部分固定费用口径。

### 8.2 项目级推断

1. 同一法人还是两个法人承担卫星代表和服务经营角色更合适；
2. 具体业务应归入 SCM、SMP、SLP 或其他服务类别；
3. 各许可、协调、认证和站点流程的实际并行顺序。

### 8.3 待确认

1. D2D、IoT 和用户终端直连的现行服务分类；
2. 各类终端的批量许可、简化或豁免条件；
3. 项目适用频段的协调结果和独立频率授权；
4. 全部项目费用和完整审批周期。
