# 巴西案例索引

## 1. 案例名称

Spacesail 在巴西开展卫星业务的落地许可流程。

## 2. 案例用途

本案例用于作为其他国家卫星落地许可分析的参考样板。原始 Spacesail 报告已于 2026 年 7 月按 Anatel 官方来源复核，正式 cases 结论以 source notes 和官方原文为依据，修订记录见 [[11_brazil_report_review|Spacesail 报告复核]]。

当后续分析泰国、蒙古、印尼、墨西哥等国家的卫星落地许可流程时，应参考本案例的模块划分，但不得直接假设目标国家的许可体系与巴西相同。

## 3. 巴西案例核心结论

Spacesail 在巴西开展卫星通信业务时，需要重点关注以下事项：

1. 外国卫星开发权 / 落地权；
2. 面向终端用户的电信服务授权；
3. 频率协调；
4. 设备认证和批准；
5. 地面站、网关站和空间站许可；
6. 相关费用；
7. 适用法规。

上述事项并非每个项目都以相同方式同时适用。仅批发卫星容量与直接面向终端用户提供电信服务的许可组合不同；SBH / SBS 双主体也是项目设计，不是巴西法规统一强制的公司架构。

## 5. 使用方式

Agent 在分析其他国家卫星落地许可时，应：

1. 先读取 common 文件夹中的国家落地许可分析 SOP；
2. 再读取本巴西案例索引；
3. 根据任务需要读取具体模块文件；
4. 将巴西流程作为检查清单和对比基准；
5. 对目标国家进行开放式检索；
6. 标记无法确认的信息为“待确认”。

## 6. 证据层入口

巴西案例的证据读取顺序为：

1. [[raw/landing_rights/brazil/source_inventory|巴西卫星落地许可来源清单]]；
2. [[raw/landing_rights/brazil/source_notes/source_notes_index|巴西卫星落地许可 Source Notes 索引]]；
3. 与问题相关的单个 source note；
4. `wiki/raw/landing_rights/brazil/sources/` 中的原始网页或 PDF；
5. 本目录下的 `01-10` 正式 cases 文件。

原始 Spacesail 报告用于解释项目背景和历史判断，不再作为缺少官方依据时的替代证据。
