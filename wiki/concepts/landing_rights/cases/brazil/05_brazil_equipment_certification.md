# 巴西设备认证

## 1. 基本要求

在巴西，受强制性合格评定范围约束、用于电信并拟合法商业化或使用的产品，需要按照适用技术要求完成合格评定并取得 Anatel homologation。

不能把该要求简化成“所有网络设备和用户设备一律采用相同流程”。是否需要认证、采用哪种评定模式、测试项目和标签要求，应按产品类别、射频参数、用途和最新技术规则逐项判断。

## 2. 适用设备

可能涉及认证评估的设备包括：

1. 用户终端；
2. 网关设备；
3. 网络设备；
4. 地面站设备；
5. 其他电信产品。

## 3. 认证与 homologation 流程

典型流程包括：

1. 确认产品类别和适用技术要求；
2. 选择认证范围匹配的 Anatel 指定认证机构（OCD）；
3. 按要求完成文件评审和实验室测试；
4. OCD 签发合格证书；
5. 向 Anatel申请 homologation；
6. 按要求完成标识、进口、商业化和持续合规事项。

OCD 证书是 Anatel homologation 的前提，但两者不是同一文件。

Spacesail 报告提到 CPQD。官方名单显示 CPQD 是多家 OCD 中的一家，不是法规指定的唯一机构；项目可以在认证范围合适的现行 OCD 中选择。

## 4. 法规依据

设备认证的规范基础为：

- Resolution No. 715/2019，电信产品合格评定和 homologation 的通用规则；
- 适用于具体产品类别的技术行政法令和测试要求；
- Anatel 产品认证办理页、OCD 名单和 homologated 产品查询入口。

还应结合 Anatel 产品认证办理页、OCD 名单及具体产品适用的技术行政法令。

## 5. 对其他国家分析的启发

分析其他国家时，需要确认：

1. 用户终端是否需要型号核准；
2. 网关设备是否需要认证；
3. 网络设备是否需要认证；
4. 是否要求本地实验室测试；
5. 是否接受国际认证结果；
6. 是否需要本地标签、证书编号或进口许可；
7. 设备认证是否为商业运营前置条件。

## 6. 待确认问题模板

对于其他国家，应重点确认：

1. 卫星用户终端是否需要 type approval；
2. 网关设备是否需要单独认证；
3. 是否可以基于 CE、FCC 或其他国际认证简化流程；
4. 是否需要本地样机测试；
5. 认证周期和费用是多少；
6. 设备认证是否与频率许可或服务许可绑定；
7. 是否允许终端批量认证。
