# 巴西频率协调

## 1. 基本要求

在巴西流程中，申请外国卫星开发权时需要关注频率协调问题。

申请人或其巴西法律代表应与其他相关运营商开展频率协调，并保存协调努力的记录。

## 2. 协调材料

可提交的频率协调材料包括：

1. 协调协议；
2. 协调努力证明；
3. 会议纪要；
4. 报告；
5. 视频记录；
6. 其他能够证明协调过程的材料。

## 3. 协调未完成时的条件

第 748/2021 号决议和官方申请手册允许部分尚未完成协调的 NGSO / NGSO、NGSO / GSO 或特定 GSO 情形继续申请，但申请人须：

1. 提交能够证明已开展协调工作的材料；
2. 接受相对于尚未达成协议的系统不主张干扰保护；
3. 不对相关系统造成有害干扰；
4. 在后续技术变化可能增加干扰时重新协调；
5. 遵守 Anatel 的停发和干扰处置命令。

原 Spacesail 报告把该条件概括为 primary / secondary 两类授权。已核对的官方来源并未将其定义为统一、正式的两档授权名称，因此正式案例不再使用该分类下结论。

## 4. ITU filing 与国内协调

ITU filing 是卫星网络申报资料，不等于 Anatel 的卫星开发权，也不自动建立巴西国内授权优先权。

申请时应分别核对：

1. ITU filing 和相关轨道频率信息；
2. Anatel 公布的授权卫星、协调优先级和申请中系统；
3. 与既有卫星系统的协调协议；
4. 与地面业务或其他系统的共存技术要求；
5. 需要时的共轨协议和干扰分析。

卫星开发权也不等于所有地面业务和电台已经取得独立的频率使用资格。第 777/2025 号决议表明，依赖无线电频率的服务通知，其有效性取决于取得所需频率授权，或签订覆盖该服务频段的卫星容量合同。具体地球站、网关和终端是否需要单独频率授权，应结合服务、站型和频段判断。

## 5. 对其他国家分析的启发

分析其他国家时，需要确认：

1. 是否要求频率协调；
2. 是否要求提交 ITU filing；
3. 是否要求提交协调协议；
4. 是否允许提交协调努力证明；
5. 未完成协调时是否允许在无保护、不得造成有害干扰等条件下运行；
6. 是否需要提交干扰分析或共存分析；
7. 是否存在与 GSO、NGSO、地面业务或已有运营商的协调要求。

## 6. 待确认问题模板

对于其他国家，应重点确认：

1. 是否需要在申请前完成频率协调；
2. 是否可以在未完成协调的情况下获得临时授权；
3. 是否存在正式定义的授权等级，还是仅设置无保护运行条件；
4. 是否需要向监管机构提交会议纪要、报告或技术分析；
5. 是否需要提交 I/N、C/I、EPFD 或其他干扰指标；
6. 是否要求与现有卫星运营商或地面系统运营商协调。
