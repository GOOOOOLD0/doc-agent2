# 蒙古案例可复用经验

本文件提炼蒙古案例能够用于其他国家卫星落地许可研究的方法、证据组织规则和检查清单。可复用的是研究过程，不是蒙古的许可名称、编号或实体要求。

## 1. 可复用的研究方法

### 1.1 从目标国许可分类开始

蒙古公开许可体系没有识别出名称和制度结构等同于巴西外国卫星开发权的独立许可，但明确存在卫星网络和频率等本国许可分类。该分析对应 `E-001`。

可复用的方法是：

1. 先查目标国法律中的许可清单和主管机关；
2. 再查通信法、频率法和卫星专项规则；
3. 将巴西案例只作为问题清单，不把巴西许可名称作为搜索结果的预设答案；
4. 对“未发现独立 landing rights”使用分析推断，不写成监管机构已确认的否定性结论。

### 1.2 先拆业务模型，再判断特殊路径

蒙古对移动卫星业务提供专用频率申请表，对 NTN 规定由地面移动网络经营者登记的路径。这两项证据分别对应 `E-007`、`E-008`。

研究其他国家时，应在检索前明确：

- 是 FSS、MSS、BSS、VSAT、NTN/D2D 还是只接收业务；
- 谁运营卫星网络；
- 谁持有频率；
- 网关和地球站位于哪里；
- 谁与用户签约和收费；
- 终端是固定、可搬移、移动、发射还是只接收。

不同业务可能使用不同申请表、许可和例外，不能先假定存在一条统一路径。

### 1.3 对动态公告保留检索日期

CRC 的卫星公告搜索在 2026-07-26 没有确认第 8.1.9.10 项当前窗口，该事项对应 `E-016`。

可复用的方法是：

1. 保存搜索关键词、栏目、URL、访问日期和结果；
2. 将搜索页作为更新发现入口，而不是实体法律依据；
3. 将“本次未检出”写成时点性检索结果；
4. 继续检查电子系统、其他栏目、历史公告和监管机构书面答复。

### 1.4 分开记录阶段时限和项目总周期

蒙古公开资料分别规定材料检查、遴选公告、签约、付款后发证和设备认证决定节点，但不足以形成完整项目周期。该经验对应 `E-019`。

其他国家研究也应逐项记录：

- 起算条件；
- 工作日还是自然日；
- 是否允许延期或补件；
- 是否等待申请窗口；
- 是否涉及国际协调、测试、土地或合同；
- 各程序能否并行。

不得把不同法律中的阶段时限机械相加后承诺商业开通日期。

## 3. 容易混淆的许可边界

### 3.1 未发现独立许可不等于无需批准

`E-001` 只能支持在公开体系中未识别出独立外国卫星落地权，并将研究转向目标国自己的网络、频率和配套要求。它不能支持外国卫星直接覆盖和运营。

### 3.2 MSS 专用表格不等于完整许可豁免

`E-007` 证明蒙古存在 MSS 专用频率申请表，但表格没有解决 MSS 是否完整排除卫星网络许可。其他国家出现专用表格时，也应继续核对上位许可和服务授权。

### 3.3 NTN 登记不等于外国卫星运营商零售权

`E-008` 的主体是地面移动网络经营者。分析 NTN/D2D 时必须逐字识别谁登记、谁持频率、谁运营网络、谁与用户签约，不能把技术合作能力等同于独立市场准入。

### 3.4 一般地球站属地原则不等于所有网关必须在境内

`E-020` 记录一般通信和广播卫星地球站原则上位于蒙古境内，但特殊业务可能存在不同条款。“原则上”也需要核查例外程序。其他国家出现类似措辞时，应按业务和站点功能分别分析。

### 3.5 TVRO 频率例外不等于全部合规豁免

`E-023` 只确认 TVRO 只接收终端不需要无线电频率使用许可。它不能扩大到发射终端、设备认证、进口或服务授权。

### 3.6 阶段时限不等于完整周期

`E-019` 要求保留每个时限的起算条件和程序范围。付款后发证、设备认证决定或公告期限都不能单独代表完整卫星落地周期。

### 3.7 未检出当前窗口不等于不受理申请

`E-016` 是特定日期的公开检索结果。公告可能存在于登录系统、其他栏目、不同关键词或线下渠道，必须继续向监管机构核验。

## 4. 版本、翻译和附件风险

蒙古案例形成了以下可复用控制方法：

1. **现行本地语优先**：同一法律的旧英文译文可能未同步修订，关键期限和主体措辞应回到现行官方本地语文本。
2. **批准页与附件分离**：批准决议可能只说明编号和废止关系，实体义务位于附件；应分别保存、提取和引用。
3. **网页与下载表格分离**：监管页面可能只列入口，PDF、DOCX 或 XLSX 才包含站点、设备和技术字段。
4. **无版本号表格单独标记**：MSS 和固定卫星申请表未标明明确版本时，应记录下载日期、容器页面和文件哈希。
5. **历史指导降级使用**：旧指导可以解释背景，但不能替代现行法律、技术规则或最新国际程序。
6. **动态搜索记录快照**：公告搜索结果会变化，应保存日期和关键词，不把一次“无结果”长期固化。

这些方法用于控制来源风险，不意味着蒙古出现的每一种版本问题都会在其他国家重复出现。

## 5. 可加入通用检查清单的事项

### 5.1 许可和业务

- [ ] 是否存在独立外国卫星准入文件，还是由本国网络和频率许可实现市场准入；
- [ ] FSS、MSS、BSS、VSAT、NTN/D2D 和只接收业务是否分别规定；
- [ ] 专用申请表是完整路径、附加要求还是仅处理某一许可；
- [ ] 谁运营网络、持有频率、设置网关、签约和收费。

### 5.2 站点和终端

- [ ] 一般地球站是否有属地原则及例外；
- [ ] 多站点是逐站、批量还是网络级申报；
- [ ] 用户终端、移动终端、发射终端和只接收终端是否区分；
- [ ] TVRO 或其他例外只豁免哪一项许可。

### 5.3 程序和时限

- [ ] 是否存在年度申请、遴选或招标窗口；
- [ ] 动态公告的检索日期、关键词和栏目是否留档；
- [ ] 电子系统入口是否等同于当前可提交窗口；
- [ ] 每个法定时限的起算点、延期、补件和外部依赖是否记录；
- [ ] 是否明确禁止把阶段时限写成项目总周期。

### 5.4 证据质量

- [ ] 法规主页面、附件、申请表和历史指导是否分开建 Source Note；
- [ ] 现行本地语文本和翻译版本是否核对；
- [ ] PDF、DOCX、XLSX 是否保存原件、提取文本和文件哈希；
- [ ] “未发现”结论是否保留检索范围和非穷尽性边界。

## 6. 不可迁移的国家特殊规则

以下内容是蒙古证据结论，不能直接作为其他国家事实：

1. 《许可法》第 8.1 条第 9.10 项的许可名称和编号；
2. CRC 第 37/2022 号决议附件中的 MSS、NTN 和地球站条款；
3. 地面移动网络经营者在自身频率许可范围内登记 NTN 的主体设计；
4. 一般通信和广播卫星地球站原则上位于蒙古境内的措辞；
5. TVRO 只接收终端的蒙古频率许可例外；
6. CRC 每年至少一次遴选和至少提前 30 日公告的蒙古法定节点；
7. `customer.crc.gov.mn`、CRC 表格名称和蒙古申请渠道。

研究新国家时，只能迁移检查问题、来源层级和证据边界，最终许可结论必须由该国官方来源重新建立。
